# Percentage Calculator in JavaScript

A lightweight, accessible percentage calculator built with plain HTML, CSS, and JavaScript. It supports three common calculations:

- what percent one number is of another;
- a percentage of a number;
- percentage increase or decrease.

## Features

- No frameworks or external dependencies
- Responsive layout for desktop and mobile
- Accessible labels and live result announcements
- Input validation for invalid numbers and zero denominators
- Locale-aware number formatting
- Clear formulas and result explanations

## Run locally

Download the repository and open `index.html` in a browser. No build step is required.

## Formulas

```text
Part of total       = (part / total) * 100
Percent of a number = (percentage / 100) * number
Percentage change   = ((new value - old value) / old value) * 100
```
